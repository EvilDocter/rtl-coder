Module Name: uart_tx
Description: UART Transmitter module transmitting 8 data bits with 1 start bit and 1 stop bit (8-N-1 format) with a configurable baud rate clock divider.
Port Specifications:
- clk: 1-bit input system clock (50 MHz)
- rst_n: 1-bit input synchronous active-low reset
- tx_start: 1-bit input trigger pulse to initiate transmission
- tx_data: 8-bit input parallel data byte to transmit
- tx: 1-bit output serial transmit line (idle high, 1'b1)
- tx_busy: 1-bit output status flag, high during active frame transmission
Behavior:
- On reset (rst_n low), tx is driven high (idle state) and tx_busy is 0.
- When tx_start is asserted and tx_busy is low, the module latches tx_data, asserts tx_busy, and transmits:
  1. Start bit: tx = 0 for 1 baud period
  2. Data bits: tx = tx_data[0] through tx_data[7] (LSB first), 1 baud period each
  3. Stop bit: tx = 1 for 1 baud period
- When the stop bit transmission finishes, tx_busy drops to 0.
