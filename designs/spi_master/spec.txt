Module Name: spi_master
Description: SPI Master controller supporting 8-bit full-duplex transfers with CPOL=0 and CPHA=0 (Mode 0).
Port Specifications:
- clk: 1-bit input system clock
- rst_n: 1-bit input synchronous active-low reset
- start: 1-bit input start transfer trigger
- tx_data: 8-bit input parallel data byte to transmit to slave
- sclk: 1-bit output SPI serial clock (idle low, toggles during transfer)
- mosi: 1-bit output Master-Out Slave-In serial data
- miso: 1-bit input Master-In Slave-Out serial data
- cs_n: 1-bit output active-low slave select line
- rx_data: 8-bit output parallel data byte received from slave
- busy: 1-bit output status flag, asserted during active transfer
Behavior:
- On reset (rst_n low), cs_n is high (1), sclk is low (0), mosi is low, busy is 0, and rx_data is 0.
- When start is asserted and busy is 0, cs_n is driven low, busy becomes 1, and 8 bits are shifted out on mosi while shifting in from miso.
- Upon completing 8 bits, cs_n returns high, rx_data holds the received byte, and busy returns low.
