Module Name: alu
Description: 8-bit parameterized Arithmetic Logic Unit (ALU) with arithmetic and bitwise logic operations, plus status flags (zero, carry, negative).
Port Specifications:
- clk: 1-bit input clock
- rst_n: 1-bit input synchronous active-low reset
- opcode: 3-bit input operation selector:
  * 3'b000: ADD (result = a + b)
  * 3'b001: SUB (result = a - b)
  * 3'b010: AND (result = a & b)
  * 3'b011: OR  (result = a | b)
  * 3'b100: XOR (result = a ^ b)
  * 3'b101: SHL (result = a << 1)
  * 3'b110: SHR (result = a >> 1)
  * 3'b111: PASS_A (result = a)
- a: 8-bit input operand A
- b: 8-bit input operand B
- result: 8-bit output computed result
- flag_zero: 1-bit output status flag, asserted when result == 8'd0
- flag_carry: 1-bit output status flag, asserted on addition overflow or subtraction borrow
- flag_negative: 1-bit output status flag, asserted when result[7] is 1
Behavior:
On posedge clk, when rst_n is low, all outputs and flags are cleared to 0. Otherwise, result and flags update synchronously based on the selected opcode.
